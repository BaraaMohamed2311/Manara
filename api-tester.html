⚠️ CORS Error Detected

The browser blocked the response because the server didn't send the right CORS headers on the actual response (not just on the OPTIONS preflight). This is a server-side fix, not a client-side one:

  • API Gateway (HTTP API): enable CORS on the API and set Access-Control-Allow-Origin (or your exact origin), Access-Control-Allow-Methods: GET,POST,OPTIONS.
  • API Gateway (REST API / Lambda proxy): your Lambda must include Access-Control-Allow-Origin in the headers of every response it returns (200s and errors), since Lambda proxy integrations don't add this automatically.
  • S3 bucket (for the presigned POST upload): add a CORS configuration on the bucket allowing your origin, method POST, and header *.

Once headers are added server-side, retry the request below — no changes needed here.
